# CARE-LINK


 CARE LINK is a community support platform that connects NGOs, volunteers, and donors through a single digital platform.

The platform helps organizations post requests for assistance, allows volunteers to contribute their time and skills, and enables donors to provide resources to communities in need.

## Features

* NGO Registration
* Volunteer Registration
* Donor Registration
* Community Feed
* Request Management
* Volunteer Dashboard
* NGO Dashboard
* Volunteer Ranking System
* Certificates and Recognition

## Tech Stack

* Java (JSP/Servlet)
* MySQL
* Bootstrap
* Apache Tomcat
* Eclipse IDE

## Objective

To bridge the gap between community needs and people willing to help by creating a transparent and accessible support network.
